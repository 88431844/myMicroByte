## 结构变化

- 扩大开关周围让位，取消窄台阶。十字键采用有意连通的开口，消除中间易断的小片；使用 PCB 原静音开关，无打印按键帽。
- 保留前后外缘 R1.8 圆角。面板整体降低 0.5 mm，左右按键区再下沉 0.4 mm。屏幕周围面板最薄 1.1 mm，按键区主面厚 1.2 mm。
- TF 处增加前盖遮板唇边与入口倒角，后盖留出唇边装配槽。卡片插入路径上方留至少 0.35 mm；为避免夹住 TF 卡，PCB 下缘仍保留少量可见区域。
- 拨帽从后盖上方垂直装入。贯通叉槽套住原拨杆；前盖关闭后封住敞口导轨。内翼高于外槽净高，防止合壳后拨帽横向脱出。
- 拨帽手指面有 5 条圆边防滑筋。导出打印姿态旋转为 −90°，防滑筋朝上，不接触打印平台。
- 后盖厚度和 PCB 支承高度保持 9 mm。扩宽电池框后，保守电池包络至 ESP32 约 0.68 mm，至 Type-C 约 0.40 mm，至喇叭插头约 1.83 mm。电池型号仍未选定。
- M2×2×3 热熔螺母与 M2×5 螺丝保留；名义螺纹啮合约 1.75 mm。上方余量用于容纳板厚、翘曲和螺母安装偏差，PCB 支承不靠强行夹紧。若板有轻微晃动，可在支柱处加薄绝缘垫，不压屏幕或电池。

## 文件

- `myMicrobyte_enclosure_v05.FCStd`：FreeCAD 原生装配和构造树。
- `myMicrobyte_enclosure_v05.step`：三件壳体/拨帽实体。
- `FrontShell_print.stl`、`RearShell_print.stl`、`PowerSlider_print.stl`：已归零的打印姿态，尚未切片或发送。
- `../assembly-guide-v05/index.html`：离线交互装配页面。
- `../../reports/v05/`：实际模型渲染和检查报告。

Parameters 表记录尺寸。修改生成脚本 `freecad/update_enclosure_v05.py` 的 VALUES 后重建；该表未用表达式驱动全部特征。页面位置偏移只记录调整意图，不会重建 CAD 或检查干涉。

## 验证范围与实物检查

实体与网格检查、保守元件包络、TF 插入、拨帽完整滑动和垂直装入路径见检查报告。另检查 LCD 横向 ±0.2 mm、板厚向上增加 0.2 mm，以及按钮附加 0.2 mm 焊接高度的情况。

以上是明确假设的公差场景，不能取代这块实物 PCB 的测量。前版空壳合拢、装板有缝说明存在实物接触，照片尚不能确定唯一接触点。本版扩大了几个最紧的让位；试装时先确认可自然合缝，再拧螺丝。

拨帽叉槽相对标称 1.3 mm 拨杆约有 0.65 mm 游隙，3.6 mm 塑料活动范围可覆盖约 2.95 mm 拨杆位移。实际 MSK-12C02 电气档位及打印滑动手感仍需实物确认。

根据本轮补充反馈，前盖左下角 RUN 观察孔和内侧导光漏斗已删除，恢复连续实心面板。

下次打印仍可三件同盘、黑色 PLA、拓竹 A1。前盖下沉区域和拨帽背面需检查支撑策略；切片审核在本版外观确认之后进行。
